ติดตั้งบนเครื่องตัวเอง 100% ฟรี ไม่มีค่าสมัครรายเดือน ไม่มีข้อจำกัดฟีเจอร์ ข้อมูลอยู่ในมือคุณ 100%

เปิดเดโมทันที (ไม่ต้องติดตั้ง) ดูโค้ด + วิธีติดตั้งจริง

วิธีติดตั้งจริง — จากโค้ดของระบบ

  1. เตรียมเครื่อง: Docker (จำเป็น) และ Node.js 20+ — RAM ควรมีตั้งแต่ 2GB ขึ้นไป และดิสก์ราว 10GB
  2. โคลนระบบ: git clone https://github.com/krisakornutama/sovereign-origin
  3. รันสคริปต์ติดตั้งหนึ่งครั้งจบ: tools\install\install.cmd (Windows) หรือ node tools/install/install.mjs (Linux/Mac)
  4. สคริปต์สร้างไฟล์ตั้งค่าให้เอง สตาร์ต Docker และตรวจสุขภาพจบโดยไม่ต้องตั้งค่าเอง — หน้าใช้งานอยู่ที่พอร์ต 3000

หมายเหตุ: ยังไม่มีไฟล์ติดตั้งสำเร็จรูปให้ดาวน์โหลด — ติดตั้งจากโค้ดจริงด้วยสคริปต์ข้างบน หรือลองใช้งานผ่านหน้าเดโมก่อนได้เลย
