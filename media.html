ไฟล์ไม่ต้องออกจากเครื่อง

เลือกโฟลเดอร์วิดีโอ/เพลงในเครื่อง แล้วเปิดดูได้ทันทีในหน้านี้ — ทำงานแบบอ่านไฟล์จากดิสก์โดยตรง ไม่มีการอัปโหลด ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชี พร้อมคู่มือสะสมสื่อที่มีสิทธิ์และเปิดเซิร์ฟเวอร์สื่อในบ้านให้ทุกจอดูได้แม้เน็ตตัด

ความเป็นส่วนตัว: หน้านี้อ่านไฟล์ในเครื่องอย่างเดียว — ไม่มีคำขอเน็ตเวิร์กใด ๆ ในตัวเล่นสื่อ

เลือกโฟลเดอร์สื่อ → ตั้งเซิร์ฟเวอร์ในบ้าน

// เปิดจากดิสก์โดยตรง · ไม่อัปโหลด

เปิดโฟลเดอร์สื่อในเครื่อง

กดปุ่มเลือกโฟลเดอร์ (Chrome/Edge แนะนำ) รายการไฟล์จะโผล่ข้างล่าง กดไฟล์ไหนก็เล่นไฟล์นั้น — ทำงานได้แม้เน็ตตัด เพราะทุกอย่างเกิดในเครื่อง

เลือกโฟลเดอร์ในเครื่องแล้วรายการจะโผล่ที่นี่ — ไฟล์ไม่ถูกอัปขึ้นอินเทอร์เน็ต

ตัวเล่นสื่อจะโผล่ตรงนี้เมื่อกดไฟล์จากรายการ

// สะสมอย่างถูกสิทธิ์

เก็บสื่อที่คุณมีสิทธิ์ลงเครื่อง

คลังสื่อจะมีของให้ดูก็ต่อเมื่อมีไฟล์จริงในดิสก์ — ทางที่ถูกกฎหมายและทนทานที่สุดคือเก็บของที่คุณเป็นเจ้าของหรือมีสิทธิ์ใช้

สื่อของคุณเอง

คลิปที่คุณอัปเดตขึ้นแพลตฟอร์มเอง สามารถดาวน์โหลดกลับลงเครื่องได้จากเมนูของแพลตฟอร์มโดยตรง (เช่น YouTube Studio → ดาวน์โหลดวิดีโอต้นฉบับ) คุณภาพเต็มและไม่ต้องใช้เครื่องมือเสริม

สื่อที่เปิดให้ใช้ฟรี

คลัง Creative Commons, Public Domain (เช่น archive.org, Wikimedia Commons) มีไฟล์ดาวน์โหลดตรง ๆ ตามสัญญาอนุญาตของแต่ละชิ้น

เครื่องมือบันทึกที่คุณมีสิทธิ์

ชุดเครื่องมือโอเพนซอร์สอย่าง yt-dlp ช่วยเก็บสื่อได้ — ใช้ได้ก็ต่อเมื่อสื่อนั้นเป็นของคุณหรืออนุญาตให้ดาวน์โหลด ตรวจสัญญาอนุญาตและข้อตกลงของแพลตฟอร์มก่อนใช้เสมอ

สำรองสองที่

ดิสก์เดียวคือไม่มีสำรอง — คัดลอกไว้อีกที่ (ดิสก์นอก/NAS) แล้วทดลองเปิดไฟล์จากสำเนาจริงสักครั้ง

// บ้านทั้งบ้านดูได้ · LAN เท่านั้น

เซิร์ฟเวอร์สื่อในบ้าน (Jellyfin)

ถ้ามีเครื่องคอม/แผงเซิร์ฟเวอร์วิ่งตลอด ติดตั้ง Jellyfin แล้วชี้ไปที่โฟลเดอร์สื่อ — ทุกจอในบ้าน (ทีวี มือถือ แท็บเล็ต) เปิดดูผ่าน Wi-Fi บ้านได้โดยไม่ต้องมีอินเทอร์เน็ต

  • ติดตั้งในเครื่องที่เก็บไฟล์ — Docker ทางที่ง่ายที่สุด: docker run -d --name jellyfin -p 8096:8096 -v C:\MediaVault:/media jellyfin/jellyfin
  • เปิดหน้าตั้งค่าครั้งแรก — พอร์ต 8096 บนเครื่องตัวเอง (http://localhost:8096) ตั้งภาษาไทย ชี้โฟลเดอร์สื่อ สแกนไลบรารี
  • เพิ่มผู้ใช้แยกตามคน — บัญชีพ่อแม่ลูกแยกกัน กำหนดได้ว่าโปรไฟล์ไหนเห็นโฟลเดอร์ไหน
  • เปิดจากจออื่น — ใส่ IP ของเครื่องตัวเซิร์ฟเวอร์ในเบราว์เซอร์หรือแอป Jellyfin เช่น http://192.168.1.10:8096

// ตรงไปตรงมา

ข้อควรระวังของคลังสื่อ

ตรงไปตรงมา

  • อย่าอัปโหลดสื่อส่วนตัวขึ้น GitHub สาธารณะ — คลังสื่อคือของใช้ในบ้าน เก็บบนดิสก์/NAS เท่านั้น การโพสต์ไฟล์ขึ้นที่สาธารณะเพื่อ "เก็บกลอนแก้ว" เป็นการเปิดข้อมูลส่วนตัวและเสี่ยงลิขสิทธิ์พร้อมกัน
  • ไฟล์บางรูปแบบอาจเปิดไม่ได้ในเบราว์เซอร์ — เบราว์เซอร์เล่น mp4/webm/mp3 ได้กว้าง แต่ mkv/avi/เสียงบางชนิดอาจไม่เล่น แปลงเป็น mp4/mp3 หรือใช้ Jellyfin ช่วยทรานส์โค้ดให้
  • หน้านี้ไม่ใช่ที่เก็บไฟล์ — หน้านี้เป็นแค่หน้าต่างเปิดไฟล์จากดิสก์ ไฟล์จริงยังอยู่ที่โฟลเดอร์ของคุณ ไม่มีอะไรถูกคัดลอกเข้าเว็บนี้
