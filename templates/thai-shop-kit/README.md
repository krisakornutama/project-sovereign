# ชุดเทมเพลตร้านเล็ก — บัญชี / ภาษี / สต็อก

โค้ดคำนวณภาษีไทยและคลังสินค้า สำหรับร้านที่ยังไม่มีระบบมาใช้
**ไม่มี dependency ไม่มีฐานข้อมูล ไม่ต้องต่ออินเทอร์เน็ต** — ใช้ Node.js ล้วนก็พอ

---

## อยู่ในกล่องอะไรบ้าง

```
thai-shop-kit/
├── lib/
│   ├── thai-tax.mjs      คำนวณ VAT · CIT · PIT · ปฏิทินยื่นภาษี
│   ├── inventory.mjs     วันหมดอายุ · ของเหลือน้อย · หัก/เติมสต็อก
│   └── load.mjs          อ่านแม่แบบ CSV → ข้อมูลที่คำนวณได้
├── data/
│   ├── ledger.csv        แม่แบบบัญชีรายรับ-รายจ่าย (พร้อมตัวอย่าง)
│   └── inventory.csv     แม่แบบคลังสินค้า (พร้อมตัวอย่าง)
└── test/                 เทสต์ของตัวเอง 125 ข้อ (รันได้ทันที)
```

## เริ่มใช้

```bash
node --test "test/*.test.mjs"     # เทสต์ตัวเองก่อน ต้องผ่าน 125/125
```

ขั้นที่ 1 — ทำบัญชีของร้านตัวเอง

```js
import { readFileSync } from 'node:fs';
import { readLedgerCsv } from './lib/load.mjs';
import { businessTaxOverview } from './lib/thai-tax.mjs';

const { rows, skipped } = readLedgerCsv(readFileSync('data/ledger.csv', 'utf8'));
if (skipped) console.warn(`ข้าม ${skipped} แถวที่อ่านไม่ถูกต้อง — ลองเปิดไฟล์ดู`);

const o = businessTaxOverview({ vatRate: 0.07, salesPayments: [], ledger: rows });
console.log(o.vat.thisMonth.netVat);   // VAT ที่ต้องจ่ายงวดนี้
console.log(o.cit.taxDue);             // ภ.ง.ด.50 ที่ต้องจ่ายเพิ่ม
console.log(o.calendar);               // วันครบกำหนดทั้ง 5 ใบ
```

> อย่าลืมใส่ `now` ตอนทดสอบ เช่น `now: new Date('2026-10-06')` จะได้ผลคงที่เสมอ

ขั้นที่ 2 — ดูว่าอะไรใกล้หมดอายุ / ของเหลือน้อย

```js
import { readInventoryCsv } from './lib/load.mjs';

const { rows } = readInventoryCsv(readFileSync('data/inventory.csv', 'utf8'), new Date());
for (const r of rows) {
  if (r.expiry.status === 'expiring') console.log(`ใกล้หมดอายุ ${r.expiry.daysLeft} วัน: ${r.name}`);
  if (r.stock.low) console.log(`ของเหลือน้อย: ${r.name} (เหลือ ${r.quantity} / ขั้นต่ำ ${r.stock.minimumStock})`);
}
```

ขั้นที่ 3 — หักสต็อกตอนขาย

```js
import { deductStock } from './lib/inventory.mjs';
const r = await deductStock(yourStore, itemId, 2);
if (!r.ok) console.warn(r.reason);   // ของไม่พอ → บอกเจ้าของร้านก่อน
```

`deductStock` / `addStock` ต้องการแค่ออบเจกต์ที่มี `inventoryItem.findUnique()`
และ `inventoryItem.update()` — ถ้าใช้ Prisma ก็ส่ง `prisma` เข้าไปตรง ๆ ได้
ถ้าไม่ได้ใช้ฐานข้อมูล เขียนสองฟังก์ชันนี้ขึ้นมาเองได้ใน 5 บรรทัด

## คอลัมน์ที่ใช้ได้

**`ledger.csv`** — ชื่อคอลัมน์ภาษาไทยหรืออังกฤษก็ได้ แต่ต้องมี 3 ช่องนี้เสมอ

| คอลัมน์ | จำเป็น | หมายเหตุ |
| --- | --- | --- |
| `วันที่` | ✅ | เขียน `YYYY-MM-DD` เท่านั้น รูปแบบอื่นจะถูกข้าม |
| `ประเภท` | ✅ | `รายรับ`/`INCOME` หรือ `รายจ่าย`/`EXPENSE` |
| `จำนวนเงิน` | ✅ | ใส่ `฿` และจุลภาคได้ เช่น `฿1,234.50` |
| `ภาษี VAT` | — | ภาษีซื้อ/ขายที่จ่ายจริง ไม่ใส่ = 0 |
| `หัก ณ ที่จ่าย` | — | ยอดที่ถูกหักไว้แล้ว ไม่ใส่ = 0 |
| `หมวด` | — | ป้ายกำกับเอง เช่น `SALE` `COGS` `RENT` |

**`inventory.csv`**

| คอลัมน์ | จำเป็น | หมายเหตุ |
| --- | --- | --- |
| `ชื่อสินค้า` | ✅ | |
| `หมวด` | ✅ | ต้องเป็นหนึ่งใน 11 หมวดด้านล่าง (เขียนเล็กได้) |
| `จำนวน` | ✅ | |
| `รหัส` | — | รหัสเอง/เลข SKU |
| `ขั้นต่ำ` | — | เตือนเมื่อเหลือต่ำกว่านี้ ไม่ใส่ = ไม่เตือน |
| `อายุเก็บ (วัน)` | — | ใช้คิดวันหมดอายุ ไม่ใส่ = ไม่มีวันหมดอายุ |
| `วันที่ซื้อ` | — | นับวันหมดอายุจากวันนี้ขึ้นไป ไม่ใส่ = นับจากวันที่รันโค้ด |

หมวดสินค้า 11 หมวด: `WATER` `FOOD` `SEED` `FUEL` `MEDICINE` `TOOL` `MATERIAL`
`PRECIOUS_METAL` `COMPOST` `FERTILIZER` `OTHER`

## สิ่งที่ตั้งใจทำให้ชัดเจน

**แถวที่อ่านไม่ถูกต้องจะถูกข้ามและนับ ไม่ใช่เดา**
วันที่ผิดรูป จำนวนเงินเป็นตัวอักษร หรือหมวดที่ไม่รู้จัก → ไม่เข้าไปปนกับตัวเลขที่ดี
ทุกครั้งที่อ่านจะได้ `{ rows, skipped }` ให้เช็คเสมอ ถ้า `skipped` ไม่ใช่ 0
ให้เปิดไฟล์ตรวจก่อน เพราะตัวเลขที่หายไปเงียบ ๆ แย่กว่าที่ไม่มีตัวเลขเลย

**ตัวเลขอะไรก็ตามที่คำนวณได้ แต่ไม่ได้ยื่นให้**
นี่คือตัวช่วยคิดเลข ไม่ใช่ที่ปรึกษาภาษี แบบภาษีจริงต้องดูรายการที่เกิดจริง
ลดหย่อน/ค่าใช้จ่ายส่วนตัวที่ใช้เต็มรูปแบบ และกรณีเฉพาะของแต่ละร้าน ให้ผู้เชี่ยวชาญตรวจ

**อัตราใน `RATES` คือที่มาเดียวของตัวเลขทั้งชุด**
แก้ที่นี่ที่เดียว อย่าไปเขียนเปอร์เซ็นต์แยกในโค้ดส่วนอื่น

## ตัวเลขภาษีที่ใช้อยู่

อ้างอิงประมวลรัษฎากร ณ **ก.ย. 2026**

| เรื่อง | อัตรา/เกณฑ์ |
| --- | --- |
| VAT | 7% ถึง **30 ก.ย. 2027** แล้วกลับเป็น 10% |
| ภ.ง.ด.50 (SME) | ทุนจดทะเบียน ≤ 5 ล้าน **และ** รายได้รวม ≤ 30 ล้าน → 0% / 15% / 20% |
| ภ.ง.ด.50 (ทั่วไป) | 20% |
| ภ.ง.ด.90/91 | 0–35% แบบ 8 ขั้น (คิดหลังหักค่าใช้จ่ายส่วนตัว 60,000) |

อัตรา VAT มีวันสิ้นสุด ตัวโค้ดเช็กให้เองด้วย `currentVatRate(date)` —
วันที่ผ่าน 30 ก.ย. 2027 ไปแล้วจะได้ 0.10 เอง ไม่ต้องแก้โค้ด

> ภาษีไทยเปลี่ยนบ่อย ให้ตรวจกับกรมสรรพากรก่อนยื่นทุกครั้ง

## ที่มาของโค้ด

ดึงมาจาก `sovereign-os/core-api/src/services/` ของโครงการ **sovereign-origin**
(`thai-tax.service.ts` และ `inventory.service.ts`) แปลงเป็น JavaScript ที่ไม่พึ่ง
dependency และไม่ผูกกับฐานข้อมูล แล้วเขียนชุดเทสต์ใหม่ทั้งหมด (เทสต์ของต้นฉบับเป็น
integration test ที่ต้องต่อ Prisma จึงใช้เป็นหลักฐานว่าตรรกะถูกต้องไม่ได้)

**แก้จากต้นฉบับ 1 จุด:** `endOfMonth()` เดิมรับเดือนนอกช่วง 1–12 ได้ เช่น
`endOfMonth('2026-13')` คืน `2027-01-31` คือคำนวณงวดภาษีของเดือนที่ไม่มีอยู่จริง
จึงเพิ่มการตรวจช่วงให้โยน error — ถ้าคุณใช้เวอร์ชันต้นฉบับ ควรแก้จุดเดียวกัน
