SOVEREIGN · NFC CHECK-IN กำลังตรวจเบราว์เซอร์…

ระบบบันทึกงานฟาร์มด้วยแท็ก NFC

แตะแท็ก = บันทึก ใคร ทำ อะไร ที่ จุดไหน พร้อมเวลาจริง — ข้อมูลทั้งหมดเก็บในเบราว์เซอร์ของเครื่องนี้เท่านั้น (IndexedDB) ไม่มีเซิร์ฟเวอร์กลาง ไม่มีอินเทอร์เน็ต และส่งออกเป็นไฟล์ JSON ได้ทุกเมื่อ

บันทึกรายการ

ฟังแท็ก: เปิดครั้งเดียวแล้วแตะได้ต่อเนื่องทีละแท็ก · เขียนแท็ก: ต้องกดปุ่มทุกครั้งตามมาตรฐานความปลอดภัยของเบราว์เซอร์

ประวัติการเช็คอิน

เวลาผู้ทำงานชนิดงานแหล่งที่มา

ยังไม่มีรายการ — กด "จำลองแตะแท็ก" เพื่อทดสอบ หรือแตะแท็กจริง (ต้องมี Chrome บนมือถือ Android + แท็ก NFC)
