แดชบอร์ดเซนเซอร์ไร้สาย (Web Bluetooth)

เชื่อมต่อตรงกับบอร์ดเซนเซอร์ (ESP32/BLE, อุปกรณ์มาตรฐาน SIG) เพื่ออ่านดิบ ๆ แล้วแสดง live ที่นี้ — ไม่ผ่าน Cloud Broker ไม่ต้องมี Gateway/อินเทอร์เน็ต ทุกเทคนิคและทุกค่าถูกบันทึกลง IndexedDB ในเบราว์เซอร์ของเครื่องนี้ พร้อมส่งออกเป็น JSON ทุกเมื่อ

PRESET GATT ที่ค้นหาอัตโนมัติเมื่อเชื่อมต่อ
อุณหภูมิ/ความชื้น: 0x181A → 0x2A6E (sint16 LE ÷100 °C), 0x2A6F (uint16 LE ÷100 %) · แบตเตอรี่: 0x180F → 0x2A19 (uint8 %) · ชีพจร: 0x180D → 0x2A37 (uint8/uint16 bpm) · ESP32 Custom UART: 6E400001… (Nordic NUS) → TX 6E400003… (ข้อความ/JSON)
