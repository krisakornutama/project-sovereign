SOVEREIGN OS · ซอฟต์แวร์ธุรกิจ ติดตั้งเอง

ระบบหลังบ้านธุรกิจ ที่คุณ โฮสต์เอง ขายของได้ตั้งแต่วันแรก

Sovereign OS คือระบบปฏิบัติการธุรกิจสำหรับร้านเล็ก ฟาร์ม และสต็อก ครบชุดในตัว — POS ขายหน้าร้าน สต็อกสินค้า ปศุสัตว์และฟาร์ม พลังงาน การเงิน เภสัชกรรม และควบคุมรถขนส่ง — รันบน Electron desktop client กับ Node.js API โฮสต์เองบนเครื่องของคุณ ไม่ต้องเช่าคลาวด์ ไม่มีค่ารายเดือน ไม่ส่งข้อมูลธุรกิจออกนอกเครื่อง

Next.js 16.3 (Pages Router · Turbopack) · Express 4.22 · PostgreSQL + TimescaleDB · Prisma · Electron · Docker Compose

// หลักฐาน

ทุกคำอ้างอิงบนหน้านี้ ตรวจสอบจริงได้จากคำสั่งในตัวติดตั้ง

ไม่มีตัวเลขที่แต่งขึ้น ไม่มีรีวิวปลอม ทุกประโยคอ้างอิงถึงไฟล์หรือคำสั่งที่ส่งมอบมาพร้อมตัวติดตั้ง

สิ่งที่อ้างอิงคำสั่งที่รันได้จริงผลลัพธ์ที่คาดหวัง
ตัวติดตั้งสะอาด ไม่มีข้อมูลลับ git grep -nE 'sk_live_|whsec_|ghp_|BEGIN (RSA|OPENSSH|EC) PRIVATE KEY' คืนค่าว่าง (ไม่เจอตัวอักษรลับใด ๆ)
ตัวติดตั้งติดตั้งได้บนเครื่องเปล่า npm ci && npm run verify exit code 0 (arch gate + frontend gate + backend build/test + frontend typecheck/build ผ่านทั้งหมด)
ทดสอบกับฐานข้อมูลจริง npm run test:db exit code 0 (เชื่อมต่อ PostgreSQL + TimescaleDB จริง)
ทดสอบ end-to-end ในเบราว์เซอร์จริง npm run e2e exit code 0 (Playwright ครบทุกเคส)
เช็คโค้ด TypeScript ของฟรอนต์เอนด์ npm run test:tools ภายใน npm run verify exit code 0 (เครื่องมือ SEO / preflight ผ่าน)

คำสั่งทั้งหมดอยู่ในไฟล์ package.json ของตัวติดตั้ง รันบนเครื่องคุณเองได้ทันทีหลังแตกไฟล์ ZIP

// ติดตั้ง 3 ขั้นตอน

เริ่มใช้งานใน 3 ขั้นตอน

ตัวติดตั้งมาพร้อม INSTALL.cmd หากเครื่องคุณยังไม่มี Node.js หรือ Docker ตัวติดตั้งจะติดตั้งให้ หรือแจ้งข้อความที่แก้ไขได้ทันที

ขั้นที่ ๑

ดาวน์โหลดไฟล์ sovereign-os-<version>.zip จากหน้าร้าน แล้วแตกไฟล์ลงโฟลเดอร์ที่คุณเลือก

ขั้นที่ ๒

เรียก INSTALL.cmd ตัวติดตั้งจะตรวจว่าเครื่องคุณมี Node.js และ Docker หรือไม่ ถ้ายังไม่มีจะติดตั้งให้ หรือบอกขั้นตอนต่อไปอย่างชัดเจน

ขั้นที่ ๓

เปิดแอปเดสก์ท็อป Sovereign OS เข้าสู่ระบบ และเริ่มใช้งานโมดูลที่ธุรกิจของคุณต้องการได้ทันที

ถอนการติดตั้งล้างสะอาด: ลบบริการ เวิร์กฟローที่ตั้งไว้ และตัวเลือกสั้น (shortcut) โดยไม่ทิ้งเศษไฟล์ไว้บนเครื่อง

// คำถามพบบ่อย

ถามก่อนซื้อ

อัปเดตซอฟต์แวร์ทำอย่างไร?

หลังซื้อ คุณจะได้รับไฟล์ ZIP เวอร์ชันใหม่ผ่านอีเมลที่ใช้ซื้อ แตกไฟล์ทับโฟลเดอร์เดิมแล้วเรียก INSTALL.cmd อีกครั้ง หากซื้อแผน Pro หรือ Business คุณยังได้คำเชิญเข้า private repo เพื่อดึงโค้ดเวอร์ชันล่าสุดได้เอง

คืนเงินได้หรือไม่?

ได้ ภายในระยะเวลาที่กำหนดในหน้าชำระเงิน เมื่อคืนเงินสำเร็จใบอนุญาตจะถูกเพิกถอน และการเข้าถึง private repo (ถ้ามี) จะถูกยกเลิกโดยอัตโนมัติ

ต้องมีบัญชี GitHub หรือไม่?

ไม่จำเป็น คุณจะได้รับไฟล์ ZIP ตัวติดตั้งเสมอแม้ไม่มีบัญชี GitHub คำเชิญเข้า repo เป็นสิทธิพิเศษสำหรับแผน Pro และ Business เท่านั้น

ต้องต่ออินเทอร์เน็ตตลอดเวลาหรือไม่?

ไม่ต้อง Sovereign OS โฮสต์เองบนเครื่องของคุณ ทำงานออฟไลน์ได้เต็มที่ ต้องใช้อินเทอร์เน็ตเฉพาะตอนดาวน์โหลดตัวติดตั้งและตรวจสอบใบอนุญาตครั้งแรกเท่านั้น

ข้อมูลของฉันออกจากเครื่องหรือไม่?

ไม่ Sovereign OS ไม่พึ่งคลาวด์ ฐานข้อมูลและไฟล์ทั้งหมดอยู่บนเครื่องคุณ ไม่มีการส่งข้อมูลธุรกิจไปยังเซิร์ฟเวอร์ภายนอก

ใช้ภาษาอะไรสร้าง?

Next.js 16.3 (Pages Router + Turbopack) สำหรับฟรอนต์เอนด์ Express 4.22 สำหรับ API ฝั่งเซิร์ฟเวอร์ PostgreSQL + TimescaleDB สำหรับฐานข้อมูล Prisma สำหรับ ORM และ Electron สำหรับแอปเดสก์ท็อป ไม่มี NestJS ไม่มี Next.js 14 ไม่มี Kubernetes ไม่มีระบบหลายผู้เช่า (multi-tenant) และไม่ต้องพึ่งคลาวด์

ทดสอบก่อนซื้อได้หรือไม่?

ตัวติดตั้งมีโหมดทดลองใช้จำกัดเวลา เต็มทุกฟีเจอร์ ใช้ได้จนกว่าหมดเวลาทดลอง หากพอใจค่อยซื้อใบอนุญาตเต็มรูปแบบ

ซื้อแล้วได้อะไรบ้าง?

ได้รับไฟล์ ZIP ตัวติดตั้ง คู่มือการใช้งาน (.md) ใบอนุญาต (.txt) และอีเมลยืนยันพร้อมคีย์ใบอนุญาต หากเลือกแผนที่มีคำเชิญเข้าระบบ จะได้รับลิงก์คำเชิญในอีเมลฉบับเดียวกัน

พร้อมเริ่มใช้งานแล้วหรือยัง?

ซื้อ Sovereign OS แล้วรับคีย์ใบอนุญาตและลิงก์ดาวน์โหลด ZIP ทันทีทางอีเมล
